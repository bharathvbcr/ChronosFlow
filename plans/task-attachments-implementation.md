# Task Attachments Implementation Plan

## Scope

Add hybrid task attachments across domain, Room persistence, task form UX, and task opening behavior.

## Work items

1. Extend the task domain model with attachment types, storage mode, and featured-image support.
2. Persist attachments in Room with migration coverage and repository mapping.
3. Add attachment draft handling for SAF picker results, linked URI persistence, and import-copy file storage.
4. Extend the task form to manage attachments, featured images, and mode selection.
5. Extend task cards to summarize and open attachments.
6. Verify with focused domain, repository, task-form logic, and DAO tests.
